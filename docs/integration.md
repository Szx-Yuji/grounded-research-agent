# 来源与整合取舍

Grounded Research 将两个已有本地项目整合成持续对话应用，在新目录补充执行可靠性、检索评价和标准工具入口。原项目、密钥与业务数据不被覆盖。

| 来源 | 原目录 | 保留和复用 |
|---|---|---|
| 企业知识库 RAG | `../enterprise-rag-assistant` | FastAPI、React、SQLModel/Alembic、PostgreSQL、JWT、文档生命周期、Chroma 与问答 |
| 多智能体研究 | `../multi-agent-research` | Planner、Researcher、Refiner、Analyst、Writer、LangGraph、Tavily 和进度事件 |

企业知识库源于 FastAPI 全栈模板，原许可含 Sebastián Ramírez 和本地修改者声明；研究助手许可含 Puru Saluja 和本地修改者声明。两者为 MIT，保留版权和许可。第三方依赖适用各自许可。

## 会话连接能力

主入口 `/chat` 保存来源选择、历史和摘要。主 Agent 调用 RAG、研究或搜索，把结果带回当前对话。复用企业知识库的一套身份与归属，研究项目的独立账户、SQLite 历史和前端不作为第二套应用运行。

原独立知识库问答和研究接口保留用于回归与学习；这些入口与统一主 Agent 存在不同路径，某条路径的验证不能代替全部入口。

## 新增工程层

| 原问题 | 新实现 |
|---|---|
| 两个界面之间手动搬运答案 | 统一会话、主 Agent、摘要和子 Agent 笔记 |
| 内存任务随进程消失 | PostgreSQL 意图队列和独立 worker |
| 上传任务尚未索引，API 已重启 | 文档索引意图入队，ready/分块/任务终态受 lease 保护发布 |
| 失联执行误重跑或迟到写库 | lease、写入栅栏和不确定结果终止 |
| 客户端重发可能重复入队 | 按用户与业务范围验证的可选 Idempotency-Key |
| 术语/型号只靠向量召回难解释 | 词法检索、向量候选、RRF 和版本元信息 |
| 问题难定位到外部调用 | 请求编号、数据库 trace、共享预算与 usage 完整性 |
| 工具局限于本界面 | 官方 MCP SDK 只读 stdio 适配器 |
| 所有流程塞入长提示词 | 三个已审核本地 Skills 按需加载 |

没有为了追逐名称全量迁移到 Deep Agents、OpenHands 或 Langfuse。它们的适用范围和官方来源见 [生态核查](ecosystem-research-20261029.md)，后续比较需要同一任务集与可重复结果。

## 数据与迁移

新项目独立初始化 `.env`、管理员、数据库、文档和向量目录，不自动导入旧账户、文件、向量、历史或任务。旧数据导入需要额外的用户映射、来源校验、备份与回滚方案。

数据库迁移只改结构，不调用供应商重建向量。旧文档可走明确标记的兼容路径；词法投影和向量重建由显式命令处理，见 [运维说明](operations.md)。

## 实际保证

队列耐久性不等于研究图每节点续跑，lease 不等于恰好一次收费，Token 预留不等于精确金额，引用也不代表每句事实已经核验。摘要不是无限准确记忆。

原项目性能数字、Redis 多进程声明、旧截图和测试数量不直接成为新架构结果。本次实际验证、替身范围与未完成的付费联调见 [verification.md](verification.md)。
