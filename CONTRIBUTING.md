# Contributing to Grounded

Report bugs and propose changes in this project's
[issues](https://github.com/Szx-Yuji/enterprise-rag-assistant/issues).
Include reproduction steps and expected behavior, without API keys, passwords,
uploaded private documents, or other sensitive data.

## Development

See [README.md](README.md) for setup and quality checks, and
[development.md](development.md) for local development details.

## Pull requests

Keep each change focused. Explain the problem, resulting behavior, and checks
performed. Update relevant documentation and tests when behavior changes.

Review generated API clients and dependency changes before committing them.
Keep real environment files, databases, uploads, and credentials out of Git.
